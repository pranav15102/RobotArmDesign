# 6-DOF Robotic Arm – for Low-Cost Pick-and-Place Automation

## 🛠️ Problem Statement
Affordable, modular robotic arms are essential in educational and small-scale manufacturing but are limited in the market.

## ✅ Solution
Created a fully articulated 6-DOF robotic arm that is modular, low-cost, and customizable for real-world use.

## 🧠 Technical Approach
- Designed in SolidWorks with six revolute joints
- End-effector grip designed for varied component shapes
- Bolt-based modularity for easy part replacement

## 📊 Key Outcomes
- Verified articulation and reach in simulation
- Ready for integration with servo/stepper control
- Ideal for education, prototyping, and research
